Isolation & Sandbox Architecture

SafeBox implements a multi-tier defense-in-depth model specifically engineered for untrusted agent-generated code.

LAYER 1 Static AST & Heuristic Pre-Execution Analyzer

Traverses AST to reject forbidden syscalls (process spawning, shell invocation, secret paths, credential harvesting) before passing to any engine.

⬇ Passes verified payload or drops attack
LAYER 2 Dual-Engine Isolation Virtualization

JavaScript/TypeScript: Hermetic V8 Isolate with custom virtualized prototype bindings (< 1ms cold start).
Python: Ephemeral quarantined process jail with sanitized environment (zero host tokens inherited).

⬇ Active runtime supervision
LAYER 3 Hardware Quota Watchdog & Memory Guard

Hardware timers enforce hard timeouts (e.g. 3,000ms), output truncation (512KB max), and force-terminates runaway fork bombs or infinite loops.

Integrate SafeBox with Any AI Agent

Use this simple REST endpoint in your LangChain, AutoGen, CrewAI, or custom LLM harness to execute generated tool code safely.

HTTP POST /api/v1/execute 
curl -X POST http://localhost:4000/api/v1/execute \
  -H "Content-Type: application/json" \
  -d '{
    "code": "console.log(40 + 2);",
    "language": "javascript",
    "limits": {
      "timeoutMs": 2500,
      "memoryLimitMb": 64,
      "allowNetwork": false
    }
  }'
